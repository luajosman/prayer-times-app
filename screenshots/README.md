# Screenshots

Lege hier alle Screenshots ab, die im Root-[README.md](../README.md) verwendet werden sollen.

Empfohlene Benennung:

- `home-dark.png`
- `home-light.png`
- `qibla-card.png`
- `settings-theme.png`

Verwendung im Root-README:

```md
![Home Screen](screenshots/home-dark.png)
```

Oder mit Titel:

```md
![Qibla](screenshots/qibla-card.png "Qibla Card")
```

Wenn du später mehrere Varianten brauchst, kannst du auch Unterordner anlegen, zum Beispiel:

- `screenshots/android/`
- `screenshots/ios/`
- `screenshots/light/`
- `screenshots/dark/`
